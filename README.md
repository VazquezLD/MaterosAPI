# Ejecutar
1. Clonar repositorio
2. Ejecutar el siguiente comando
```
npm install
```
3. Instalar Nest CLI
```
npm i -g @nestjs/cli 
```
4. Levantar base de datos
```
docker-compose up -d
```

## Stack usado
* MongoDB
* NestJS
* Docker
